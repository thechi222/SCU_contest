# 八分鐘現場展示腳本

## 開始前

投影片使用 `presentation/算力接力站-決賽簡報草稿.pptx`。當中的待實測欄位必須在決賽前以真實紀錄替換。先確認官網當年度規範，再安排最終繳件，不沿用未確認的年份與日期。

三台電腦插電並接同一區域網路。中央服務放在穩定主機，故障示範選另外一台。投影管理者「展示總覽」，另外準備兩個學生帳號。示範素材必須自製或有使用權。

每張 GPU 同時一件工作，每位同學預設最多同時兩件，所以三機協作展示使用兩個帳號。先排練確定任務夠短，也有足夠長的工作可以展示 OFF。

## 常見追問

**可以把三張 4 GB 顯卡當成一張 12 GB 嗎？**

這版以不同 GPU 處理不同檔案，提高批次吞吐量。沒有跨機合併顯示記憶體，也不提供大型模型跨機訓練。

**OFF 後如何繼續？**

停止當前容器，未完成的檔案重新排隊並重新執行。這版沒有搬移 CUDA 記憶體或模型內部進度。

**怎樣證明真的用了 GPU？**

容器必須可用 CUDA 才能執行，結果保存引擎、模型、GPU UUID、image ID、推論計時與硬體監控。這是受信任設備的可追溯紀錄，尚不是防惡意機主偽造的硬體認證。

**誰能看到我的檔案？**

平台透過帳號限制存取，但管理者及處理資料的設備機主可能接觸內容，因此試用只收公開或經同意的素材。正式部署要有校方設備與資料管理政策。

**為什麼不用既有雲端？**

這次要驗證校內既有設備能否讓同學方便地完成固定任務，並讓機主保有控制權。成本、等待時間和品質是否比雲端適合，要以試辦資料評估。

## 備援與錄影

現場故障時先說明目前狀態，再播放「先前實機錄製」的備援影片。不能用模擬節點或假進度包裝成三台電腦即時執行。

錄影素材：登入與上傳、三台電腦同框、GPU 工作狀態、OFF / 記憶體下降、接手紀錄與下載成果。人氣獎短片可剪成約三分鐘，最終長度及截止時間需再核對當年度官網。

本次尚未連接另外兩台實機，完整三機影片與三次排練紀錄仍待團隊實際完成。平台與拍攝腳本已準備，不以合成影片冒充實機證據。
