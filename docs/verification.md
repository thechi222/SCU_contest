## 發現的問題

- 首次 TCP 斷線測試在 5.52 秒釋放、20.41 秒重新排隊，但重連後達到重試上限。失敗紀錄保存在 `network-results-20260916-175221.json`。後續連續 3 次成功：GPU 釋放 4.91–5.21 秒，失聯重排 19.98–20.25 秒，均在同一台 GPU 的第 2 次執行完成。目前沒有足夠證據判定首次失敗的根因，不能把三次成功視為已排除所有問題。正式展示前仍需完成三機穩定性驗收。
- 語音模型把「停止共享」辨識成「聽旨共享」、「未完成」辨識成「為完成」，且可能輸出簡體字。保留原始成果，不把人工修正後的內容當作模型原始輸出。
- 現在的圖片素材用來檢查尺寸、流程與下載。正式結果品質比較需加入有使用權的真實照片及文字圖，避免只用校準圖宣稱效果優異。

## 團隊下一輪驗收

1. 依 `deployment.md` 加入另外兩台 NVIDIA GPU，每台分別完成兩種模型的 prepare。
2. 在自備區域網路使用 HTTPS，完成三台同時執行、跨設備接力、真實斷網與外網切斷測試。
3. 以 `scripts/benchmark.py` 比較相同素材的單機／三機批次。保留所有失敗與重試，不從結果中排除慢工作。
4. 至少五位同學試用；記錄任務、遇到的問題及是否願意繼續使用。
5. 連續三次完成 8 分鐘展示後錄製成果影片與完整備援錄影。現有 PPTX 為可編輯草稿，待填數據保持明確標示。
