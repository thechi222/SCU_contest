# 架構與可靠性

瀏覽器透過同源 API/SSE 存取 FastAPI。SQLite 保存帳號、批次、工作、節點、執行紀錄、成果與事件。單程序在 `BEGIN IMMEDIATE` 交易內派工，資料庫另有「未結束節點/工作」唯一索引。

Agent 主動連線，節點不需開放入站連接埠。每 5 秒回報，分配租約 20 秒。租約逾時或 OFF 後，中央服務使 attempt ID 失效並重排工作。結果提交交易再次驗證 attempt、目前工作及節點共享條件，拒絕延遲結果。

工作生命周期：排隊 → 準備 → 執行 → 完成。執行失敗、OFF、逾時進入接力重試，最多兩次自動重試，即三次總執行。使用者取消直接到已取消，不自動重試。批次的每個檔案獨立計算。

中央服務每秒掃描過期工作，重啟後讀取持久化租約。重啟本身不強行宣稱工作成功，也不清空記錄。Agent 的獨立 watchdog 使用單調時鐘，續約失敗立即停止自己的容器，避免持續佔用 GPU。

## 本機停止

`enable` 建立 Agent 目錄內的 ENABLED 檔案，`stop` 移除它。watchdog 每 0.25 秒檢查；停止僅對本 Agent 目前的精確容器名稱執行 `docker rm -f`。不執行 GPU reset，不影響其他容器。Docker 引擎本身故障時，不能保證 stop 回應時間，需在實機驗收紀錄。

## 任務隔離

容器綁定指定 GPU，無網路，唯讀根檔案系統，移除 Linux capabilities，禁止提權，限制 CPU/RAM/PID，且只掛載該工作輸入、輸出與固定模型目錄。使用者不能提供命令、映像名稱、模型或任意參數。Windows 的 Agent 在主機取得 NVML，實際 GPU 推論在 WSL2 Linux 容器。

模型準備階段透過官方 URL 下載。Whisper 固定 Hugging Face revision。模型 SHA-256、容器 image ID、GPU/driver 及自測輸出寫入本機紀錄。後續執行前驗證，硬體或模型變動要重新測試。

結果的 `gpu_seconds` 是啟用 CUDA 的推論壁鐘計時，不是整段租約時間，也不等於純 CUDA kernel 時間。Whisper 包含解碼與迭代結果的 CPU 工作。UI 與報表保留計時方法，性能比較以 benchmark 的完整批次耗時為主。

## 權限

- 隨機測試密碼，scrypt 雜湊，HttpOnly/SameSite 登入 cookie。
- LAN 強制 TLS。API 要求同源與操作標頭，節點使用 bearer token。
- 10 分鐘一次性配對碼。撤銷設備會使 token 失效。
- 普通使用者只能查看自己的工作輸入、輸出與批次下載。
- 機主只能變更自己的共享設備，可查看平台設備基本狀態。
- 管理者可管理全部資料，停用帳號、取消工作與撤銷節點。

此版本以受信任的校內管理設備為前提，未實作機密運算或可信硬體認證。惡意機主可能存取任務檔案或偽造回報。網路與容器限制降低誤操作的影響，無法取代校方設備管理與使用同意。

## 測試證據的範圍

`tests/test_platform.py` 使用暫存 SQLite 和模擬時鐘，可重現同時搶單與過期派工。其模擬結果僅驗證協定，不能證明 CUDA、三台電腦或性能提升。實機產生的結果、NVML、容器 image ID 與 benchmark JSON 才能作為對應的實測紀錄。
