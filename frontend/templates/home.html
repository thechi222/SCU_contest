提供的運算服務

固定任務由平台準備好環境與模型,使用者只需上傳檔案,不必自行安裝,也不能指定執行的指令或模型, 以降低設備提供者的風險。標示「準備中」的任務已完成介面與成果規格定義,容器尚在建置,暫不開放送出。

自由租借 GPU

固定任務無法涵蓋的需求(自行撰寫的程式、調整參數、互動式實驗),可改用租借方式: 向平台申請一段時間,由目前閒置且機主同意租借的設備啟動一個容器,使用者自行進入操作,到期自動回收。

兩種使用方式的差異
項目固定任務自由租借
使用方式上傳檔案,等待成果進入容器自行操作
可執行的內容平台定義的任務容器內可自行執行
時間依檔案長度,完成即釋放依申請時數,到期回收
設備範圍所有分享中的設備僅機主另行同意租借的設備
目前狀態語音與放大已開放初步版本,連線方式確認中

租借期間整台設備由租借者獨占,平台不會再派固定任務給該設備; 容器內的資料在結束時一併清除。申請與規範見 自由租借頁面。

閒置算力儀表板

登入後可於 閒置算力儀表板 查看目前有哪些設備閒置、 各機台的 GPU 使用率與顯示記憶體用量,以及每日累計的運算時數與完成件數。

  • 各機台狀態每分鐘留存一筆,保留兩週,供查看近期趨勢。
  • 每日用量另行彙整長期保存,取樣清除後統計數字仍在。
  • 可將每日用量匯出為 CSV,供設備提供單位報告使用情形。

資源與使用限制

平台上的設備由校內單位自願提供,型號與數量會隨提供情況變動。 登入後可於「閒置算力儀表板」查看目前可用的設備、規格與使用率。

同時執行與每日額度可由管理者依實際設備數量調整。

申請與使用流程

  1. 申請帳號

    本平台不開放自行註冊,帳號由承辦單位建立後提供。申請方式與表單待確認。

  2. 登入並修改密碼

    首次登入請立即更換初始密碼。

  3. 上傳檔案

    於「工作台」選擇任務類型、為這批檔案命名並上傳。每個檔案都是一件獨立的工作。

  4. 等待派工

    平台會把工作派給目前閒置且通過自我測試的設備。若設備中途被收回,檔案會自動重新排隊。

  5. 取回成果

    完成後可單獨下載成果,或將整批打包成 ZIP 下載。成果只有本人看得到。

提供設備流程

任何校內單位或個人都可以把自己的 GPU 電腦加入平台,並保有完全的控制權。

  1. 環境準備

    機台需具備 NVIDIA GPU、驅動程式與 Docker。執行 agent prepare 下載模型、建立容器並實跑一次 CUDA 自我測試,只有通過的任務類型會登錄。

  2. 取得配對碼

    登入後於「我的設備」取得一次性配對碼(10 分鐘有效),在機台執行 agent pair 完成登錄。

  3. 開始與停止分享

    在網站上開啟分享,或在機台本機執行 agent stop。兩者都會立即停止目前的容器,未完成的檔案由其他設備接手。

工作容器沒有網路、根檔案系統唯讀,並限制 CPU、記憶體與行程數,只掛載該次工作的輸入、輸出與固定模型目錄。 設備不需要對外開放任何連接埠。

使用規範

  • 本服務僅供校內教學、學術與研究用途,不得從事營利性商業用途。
  • 使用者應遵守資通安全相關法規與智慧財產權規定,不得上傳來源不明或未取得授權的素材。
  • 上傳內容如涉及個人資料或他人隱私(例如訪談錄音),應先取得當事人同意,並自行負責去識別化。
  • 平台管理者可查看全平台的工作紀錄以維運服務;設備提供者亦可能接觸自己設備處理中的檔案,請勿上傳高度機密資料。
  • 不得以任何方式規避使用額度、干擾派工,或影響其他使用者與設備提供者的正常使用。
  • 檔案保存期限與清除方式待確認,請自行保留原始檔案備份。
  • 違反上述規範者,管理者得停用帳號並依校內相關規定處理。

本頁規範為平台團隊草擬,正式上線前須經權責單位核定。

常見問題

我的檔案會被別人看到嗎?
其他使用者看不到。但處理該檔案的設備提供者,以及平台管理者,技術上可以接觸到,請依上述規範使用。
設備提供者中途要用電腦怎麼辦?
隨時可以關閉分享或在本機停止,執行中的容器會立即停止,未完成的檔案自動回到佇列由其他設備接手,不需要等工作結束。
工作失敗了會怎樣?
系統會自動重試,含第一次最多三次。仍然失敗時會標示原因,可在工作台手動重送。
可以自己安裝套件或跑自己的程式嗎?
固定任務不行,這是為了讓提供設備的單位能放心分享。需要自行操作時請改用自由租借, 在限定時間內進入容器使用;該功能目前為初步版本,連線方式仍在確認。
要收費嗎?
校內使用不收費。電費與設備折舊由提供設備的單位自行吸收。
